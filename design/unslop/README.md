# unslop

The default design philosophy for Grimoire (Rae, 2026-11-05). Copied from
[heydamir/unslop](https://github.com/heydamir/unslop) at commit `a6f121e` (2026-11-01).

unslop was created by Damir Sokolovsky ([@heydamir](https://x.com/heydamir)) and is licensed under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The text here is unchanged. The reference images and the
snapshot and story scripts are left out; they are in the upstream repo.

`../Design.md` says how each rule applies to this app and where Grimoire departs from a rule on purpose. When the two
disagree, `Design.md` wins, because those departures are Rae's own choices.
